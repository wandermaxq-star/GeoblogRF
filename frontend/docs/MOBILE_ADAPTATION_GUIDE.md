# 📱 Глобальный путеводитель по адаптации мобильной версии проекта

## 🎯 Цель
Адаптировать мобильную версию проекта с использованием структуры и компонентов из `geo-track-story-main`, сохранив всю функциональность текущего проекта (геймификация, карты, посты).

## 📋 Принципы адаптации

### ⚠️ UX‑заметки и критические недостатки
- **Страница ProPage** (описание преимуществ премиум‑аккаунта) должна быть доступна из мобильной навигации и/или TopBar; сейчас её нет в описании.
- **Контекстные action‑кнопки** в TopBar: они должны меняться в зависимости от открытой страницы (посты → добавить пост, карта → добавить метку, планировщик → добавить маршрут, календарь → добавить событие). Стационарная кнопка «добавить метку» на странице `posts` закрывает обзор.
- **Избегать дублирования** настроек, меню «Избранное» и других функций между BottomNavigation, TopBar и панелями; оставить один централизованный источник, показывать элемент только там, где он нужен.
- **Фиксированные элементы не должны закрывать контент.** Добавьте адекватные отступы у `MainContent` (особенно в постах), чтобы заголовки и карточки не уезжали под верхнюю панель или кнопки быстрого доступа.
- **Перемещение блоков и читабельность.** Избыточный padding/маржа, неправильное расположение элементов приводит к «сползанию» текста под кнопки; разрабатывайте макет с учётом safe‑area и следите за scroll-offset.
- Большая часть описания ниже ориентирована на перенос существующего функционала, но **UX пока почти не проработан**: неожиданное поведение, нет динамики в TopBar, нет адаптивной навигации концентрации на текущем контенте.


### ✅ Что сохраняем из текущего проекта:
- **Все сервисы** (postsService, gamificationFacade, mapFacade и т.д.)
- **Все контексты** (GamificationContext, FavoritesContext, LayoutContext и т.д.)
- **Всю бизнес-логику** (геймификация, модерация, карты)
- **Map Facade** - без изменений
- **Структуру данных** - без изменений

### 🎨 Что берем из мобильной версии:
- **BottomNavigation** - нижняя навигация
- **TopBar** - верхняя панель
- **FilterTabs** - фильтры
- **Структуру страниц** - упрощенную версию
- **CSS переменные** - для единообразия стилей
- **UI компоненты shadcn/ui** - постепенная интеграция

### 🚫 Что упрощаем для мобильных:
- **Карты** - упрощенная версия, без сложных функций
- **Планировщик** - базовая функциональность
- **Навигация** - только BottomNavigation, без боковой панели
- **Макет** - простой вертикальный layout
- **Инструменты** - не дублировать настройки/избранное и другие общие меню между TopBar, BottomNavigation и боковыми панелями; держать единую точку доступа

## 📐 Архитектура мобильной версии

### Структура макета:
```
MobileLayout
├── TopBar (фиксированная верхняя панель)
├── MainContent (flex-1 overflow-y-auto pb-bottom-nav)
│   └── Страница (PostsPage, MapPage, PlannerPage и т.д.)
└── BottomNavigation (фиксированная нижняя навигация)
```

### Условный рендеринг:
- **Десктоп** (≥768px): Sidebar + сложный макет
- **Мобильный** (<768px): TopBar + BottomNavigation + упрощенный макет

## 🔄 Условный рендеринг

### В App.tsx:
```tsx
import { useIsMobile } from './hooks/use-mobile';

function App() {
  const isMobile = useIsMobile();
  
  return (
    <BrowserRouter>
      {isMobile ? (
        <MobileLayout>
          <MobileRoutes />
        </MobileLayout>
      ) : (
        <MainLayout>
          <DesktopRoutes />
        </MainLayout>
      )}
    </BrowserRouter>
  );
}
```

### В маршрутах:
```tsx
<Route 
  path="/posts" 
  element={isMobile ? <MobilePostsPage /> : <PostsPage />}
```
